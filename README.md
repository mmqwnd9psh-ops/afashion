# AFashion - Premium Fashion Store 🛍️

A modern, responsive fashion e-commerce website built with pure HTML and CSS.

## Features ✨

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern UI** - Clean and professional user interface with smooth animations
- **Product Showcase** - Display 9 featured products with ratings and prices
- **Category Navigation** - Organized menu with dropdown categories
- **Sticky Header** - Easy navigation while scrolling
- **Featured Deals** - Hot deals and shipping info sidebar
- **Social Integration** - Footer with social media links
- **Fast Loading** - Optimized for quick page load

## How to Use 🚀

1. **Clone or Download** the repository
2. **Open `index.html`** in your web browser
3. **Customize** the content, images, and colors as needed

## Customization 🎨

### Change Logo
Edit the `.logo` text in `index.html` (line 14)

### Update Products
- Edit product names (`.pro_name`)
- Update prices (`.pro_price`)
- Replace images (change image filenames)

### Modify Colors
Edit the CSS variables in `main.css` (lines 3-8):
```css
:root {
    --col1: #FF6B6B;    /* Primary color */
    --col2: #E63946;    /* Secondary color */
    --col3: #FFFFFF;    /* White */
    --col4: #CCCCCC;    /* Gray */
    --col5: rgba(255, 107, 107, 0.08);  /* Light background */
    --col-dark: #1D3557; /* Dark text */
}
```
